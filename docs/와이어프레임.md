# 마이링크 (MyLink) 화면 와이어프레임

이 문서는 마이링크 서비스의 주요 화면 구성 요소와 화면 간 이동 흐름을 정의한 와이어프레임(Wireframe)입니다. `shadcn/ui`의 컴포넌트 배치를 기준으로 구상되었습니다.

---

## 1. 화면 이동 흐름도 (Mermaid Flowchart)

```mermaid
graph TD
    A[랜딩/로그인 화면] -->|Google Auth 로그인| B(관리자 대시보드)
    
    B --> C{탭 (Tabs) 선택}
    C -->|Links| D[링크 관리 탭]
    C -->|Profile| E[프로필 관리 탭]

    D --> D1(인라인 링크 수정)
    D --> D2(토글 및 드래그 변경)
    D --> D3[+ 새 링크 추가 버튼]
    
    E --> E1(유저네임 인라인 편집)
    E --> E2(닉네임 인라인 편집)
    E --> E3(소개글 인라인 편집)

    B -->|'내 페이지 공유' 클릭| F[퍼블릭 페이지]
    F --> F1(방문자가 링크 클릭 시 외부 사이트 이동)
```

---

## 2. 관리자 대시보드 (Admin Dashboard)

웹/모바일 브라우저 접속 환경을 모두 고려한 레이아웃입니다. 화면 중앙에 `shadcn/ui`의 Tabs 컴포넌트를 사용하여 요소를 분리합니다.

### 2.1 링크 관리 탭 (Links Tab)

```text
+-------------------------------------------------------------+
|   마이링크                          [ 내 페이지 공유 ] [ 로그아웃 ]   |
+-------------------------------------------------------------+
|                                                             |
|           [ 링크 (Links) ]      [ 프로필 (Profile) ]            |
|                                                             |
|   +-----------------------------------------------------+   |
|   | = | 파 |  [ 내 유튜브 채널 놀러오기             ]   [Toggle] |   |
|   |   | 비 |  [ https://youtube.com/my-channel   ]  [Del] |   |
|   |   | 콘 |                                             |   |
|   +-----------------------------------------------------+   |
|   | = | F |  [ 🌿 인스타그램 구경가기              ]   [Toggle] |   |
|   |   | a |  [ https://instagram.com/my-insta   ]  [Del] |   |
|   |   | v |                                             |   |
|   +-----------------------------------------------------+   |
|                                                             |
|                [ + 새 링크 추가 (Add New Link) ]                |
|                                                             |
+-------------------------------------------------------------+
```
- **요소 설명**:
  - `=`: 드래그 앤 드롭을 위한 핸들 아이콘 (Drag handle)
  - `파비콘 / Fav`: 등록된 URL에 맞춰 Google API가 자동으로 로드한 파비콘 구역
  - `[ ... ]`: 클릭 시 바로 텍스트 편집 모드로 전환되는 인라인 편집 가능 항목
  - `[Toggle]`: 방문자에게 노출 여부를 결정하는 활성/비활성 스위치
  - `[Del]`: 해당 링크 완전 삭제 버튼 (주로 휴지통 아이콘 사용)
  - `[ + 새 링크 추가 ]`: 사용자의 답변에 따라 화면 가장 하단에 배치되어, 직관적으로 카드를 하단에 덧붙여 나가는 UX를 제공함

### 2.2 프로필 관리 탭 (Profile Tab)

```text
+-------------------------------------------------------------+
|   마이링크                          [ 내 페이지 공유 ] [ 로그아웃 ]   |
+-------------------------------------------------------------+
|                                                             |
|           [ 링크 (Links) ]      [ 프로필 (Profile) ]            |
|                                                             |
|   +-----------------------------------------------------+   |
|   |  유저네임 (이름)                                         |   |
|   |  [ 홍길동                                       ] ✏️  |   |
|   |                                                     |   |
|   |  닉네임 (마이링크 URL 주소: mylink.co/hong123)            |   |
|   |  [ hong123                                      ] ✏️  |   |
|   |  ⚠️ 닉네임 변경 시 기존 접속 링크가 작동하지 않습니다.          |   |
|   |                                                     |   |
|   |  소개글 (Bio)                                           |   |
|   |  [ 안녕하세요! 개발자 홍길동의 방문을 환영합니다.         ] ✏️  |   |
|   +-----------------------------------------------------+   |
|                                                             |
+-------------------------------------------------------------+
```
- **요소 설명**:
  - `✏️`: 펜 아이콘은 클릭 시 바로 글씨를 고칠 수 있음을 명시적으로 알려줌
  - 닉네임 수정 하단에는 경고 문구를 고정적으로 명시하여, 무분별한 변경으로 인한 공유 주소 오류를 방지함

## 3. 퍼블릭 화면 (Public Page - 방문자 뷰)

방문자가 접속하는 화면입니다. 모바일 디바이스 폭 상태를 기본으로 가정한 깔끔한 중앙 정렬 UI입니다.

```text
          < 모바일 환경 기준 >
+-------------------------------------------+
|                                           |
|               홍길동 (유저네임)               |
|               @hong123 (닉네임)              |
|                                           |
|     안녕하세요! 개발자 홍길동의 방문을 환영합니다.    |
|                                           |
|  +-------------------------------------+  |
|  | Fav       유튜브 채널 구경가기          |  |
|  +-------------------------------------+  |
|                                           |
|  +-------------------------------------+  |
|  | Fav       인스타그램 구경가기           |  |
|  +-------------------------------------+  |
|                                           |
|  +-------------------------------------+  |
|  | Fav       포트폴리오 보러가기           |  |
|  +-------------------------------------+  |
|                                           |
|             Powered by MyLink             |
+-------------------------------------------+
```
- **요소 설명**:
  - 프로필 이미지 없이 텍스트(유저네임, 닉네임, Bio)만으로 깔끔하게 구성됨
  - 디자인 시스템(`shadcn/ui`)의 기본 `Button` 또는 `Card` 컴포넌트를 활용하여 화면 폭에 꽉 차는 박스 형태의 링크 구역을 형성
  - 불필요한 기능(미리보기, 이미지 업로드, 커스텀 테마)을 배제하여 미니멀한 UI 유지
