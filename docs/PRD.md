# 제품 요구사항 정의서 (PRD) - 마이링크 (MyLink)

- **버전 (Version):** 1.0
- **작성일 (Date):** 2026-04-06
- **상태 (Status):** 기획/작성 중 (In Progress)

## 1. 프로젝트 개요

### 1.1 프로젝트 명
- **마이링크 (MyLink)**

### 1.2 목적
- 크리에이터, 브랜드, 개인 사용자가 흩어져 있는 자신의 여러 소셜 미디어, 웹사이트, 포트폴리오, 쇼핑몰 등의 링크를 단 하나의 페이지(URL)로 묶어서 간편하게 공유할 수 있는 통합 링크 관리 서비스를 제공합니다.

### 1.3 대상 사용자
- **크리에이터 및 인플루언서:** 인스타그램, 유튜브, 틱톡 등 여러 플랫폼을 동시 다발적으로 운영하는 사용자
- **취업준비생 및 프리랜서:** 이력서, 포트폴리오, 깃허브, 노션 등 자신을 알릴 수 있는 여러 채널을 하나의 링크로 묶어 제출하고자 하는 사용자
- **비즈니스 및 소상공인:** 브랜드 공식 홈페이지, 스마트스토어, 카카오톡 문의 채널 등을 고객에게 한 곳에서 안내하려는 사용자

### 1.4 핵심 기술 체계
- **인증 및 백엔드:** Firebase (구글 소셜 로그인 전용 적용 및 데이터 관리)
- **디자인/UI 시스템:** `shadcn/ui` 컴포넌트 라이브러리 사용

## 3. 각 기능의 상세 설명

### 3.1 필수 기능 (Must-have)

#### 3.1.1 사용자 인증 및 계정 관리
- **소셜 로그인 전용 (Firebase):** 비밀번호나 이메일 가입 과정 없이 **오직 구글 소셜 로그인(Google Auth)**만을 활용하여 사용자들이 더욱 빠르게 연동 및 사용할 수 있도록 합니다.
- **계정 정보 설정:** 처음 구글 로그인 시, 프로필 상단에 표기될 실제 이름인 **유저네임**과 마이링크 접속 URL 접속용 고유 **닉네임**을 각각 설정합니다.

#### 3.1.2 마이링크 프로필 관리
- **인라인 편집 지원:** 프로필 편집 폼 없이, 화면 상의 텍스트를 클릭하여 바로 수정할 수 있는 인라인(Inline) 편집을 지원합니다.
- **유저네임, 닉네임, 소개글 수정:** 별도의 이미지 파일 업로드 기능 없이, 화면 내에서 텍스트 기반의 **유저네임(이름)**, **닉네임(URL용)**, **짧은 소개글(Bio)** 영역을 클릭해 자유롭게 수정할 수 있습니다.

#### 3.1.3 링크 관리
- **인라인 편집 (Inline Edit):** 링크의 제목이나 URL을 수정할 때, 개별 수정 페이지 이동 없이 목록에서 해당 텍스트를 직접 클릭하여 즉시 수정합니다.
- **링크 추가 및 삭제:** 새로운 URL 링크를 추가하거나 기존 링크를 삭제할 수 있습니다.
- **파비콘(Favicon) 구글 API 연동:** 등록한 URL을 바탕으로 **Google Favicon API**를 호출하여 대상 사이트의 파비콘 이미지를 자동으로 불러오고 카드의 좌측 아이콘으로 표시합니다.
- **활성화/비활성화:** 필요한 경우 링크를 삭제하지 않고 임시로 숨길 수 있는 활성/비활성 토글 옵션을 제공합니다.
- **순서 변경 (Drag & Drop):** 직관적인 드래그 앤 드롭 방식으로 링크 노출 순서를 변경합니다.

#### 3.1.4 퍼블릭 페이지 제공
- **퍼블릭 페이지 서빙:** 공유 목적을 위한 사용자 고유 접속 URL (`mylink.co/닉네임`)을 생성하고 접속 가능한 뷰를 제공합니다.

---

### 3.2 선택 기능 (Nice-to-have)

#### 3.2.1 방문자 통계 분석
- 전체 누적/일간 페이지 방문자 수치(Views)를 대시보드에 제공합니다.
- 개별 링크별 클릭 수, 그리고 전체 방문수 대비 클릭률(CTR) 통계를 제공하여 어떤 링크가 가장 반응이 좋은지 분석할 수 있게 합니다.

#### 3.2.2 QR 코드 자동 생성 (추가 기능)
- 사용자의 고유 마이링크 접속 URL을 QR 코드 형태로 자동 생성하고 이미지로 다운로드 받을 수 있는 기능을 제공하여 명함, 매장 홍보물 등에 활용하게 합니다.

#### 3.2.3 커스텀 도메인 및 SEO 설정
- 유료/프리미엄 기능으로 본인이 소유한 `mybrand.com` 등의 도메인을 연결합니다.
- 카카오톡이나 SNS에 공유 시 노출되는 오픈그래프(OG Tag) 이미지 및 페이지 텍스트를 커스터마이징합니다.
