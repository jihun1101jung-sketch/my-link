# 사용자 시나리오 (User Scenario) - 마이링크 (MyLink)

*본 시나리오는 사용자의 주요 목적과 그에 따른 행동을 중심으로 "사용자는 ___하기 위해 ___한다." 형식으로 작성되었습니다.*

## 1. 방문자 (Visitor): 마이링크 페이지 방문 및 이용 과정

- 방문자는 **크리에이터(소유자)가 운영하는 여러 채널과 정보를 한 곳에서 확인하기 위해** 소셜 미디어나 명함 등에 공유된 마이링크 고유 URL(`mylink.co/닉네임`)에 접속한다.
- 방문자는 **해당 페이지가 누구의 페이지이며 어떤 성격인지 파악하기 위해** 화면 상단에 위치한 프로필의 유저네임(이름)과 소개글(Bio)을 읽어본다.
- 방문자는 **자신이 원하는 콘텐츠나 사이트를 찾기 위해** 파비콘 아이콘과 제목이 표시된 링크 카드 목록을 위에서부터 아래로 훑어본다.
- 방문자는 **원하는 목적지(특정 웹사이트, 쇼핑몰, 예약 폼 등)로 이동하기 위해** 관심 있는 링크 카드를 직접 클릭한다.

---

## 2. 소유자 (Owner): 마이링크 관리 및 링크 설정 과정

### 2.1 마이링크 프로필 설정
- 소유자는 **방문자들에게 제공될 내 기본 정보를 최신 상태로 유지하기 위해** 프로필 영역의 유저네임, 닉네임, 소개글(Bio) 영역 텍스트를 화면에서 직접 클릭하여 인라인(Inline) 편집으로 즉시 수정한다.
- 소유자는 **기존에 공유된 링크로의 접속이 끊기는 불상사를 방지하기 위해** 접속 URL과 직결되는 '닉네임' 부분 수정 시 화면에 나타나는 주의/경고 알림(Warning)을 확인한 뒤 신중하게 변경을 완료한다.

### 2.2 링크 추가 및 편집
- 소유자는 **자신의 새로운 콘텐츠, SNS 채널, 혹은 홍보용 웹사이트를 방문자에게 새롭게 공유하기 위해** 관리 화면에서 [새 링크 추가] 버튼을 클릭한다.
- 소유자는 **방문자가 해당 링크가 어떤 접속처인지 명확히 인지하게 하기 위해** 생성된 링크 카드의 텍스트(제목, URL)를 클릭한 뒤 인라인 편집으로 올바른 정보를 입력한다. *(이때 시스템은 URL을 기반으로 Google Favicon API를 호출해 링크 왼쪽 아이콘을 자동 설정한다.)*
- 소유자는 **입력한 URL 경로가 올바른 목적지로 이동하는지 오타를 확인하기 위해** 수정 중인 카드의 링크를 직접 테스트 클릭해 본다.

### 2.3 링크 노출 순서 및 활성 상태 관리
- 소유자는 **가장 중요하거나 최근 업데이트된 링크를 방문자 눈에 가장 먼저 띄도록 하기 위해** 해당 링크 카드를 마우스(또는 터치)로 드래그 앤 드롭하여 목록의 최상단으로 순서를 변경한다.
- 소유자는 **특정 이벤트 기한이 만료되어 당분간 해당 링크를 사람들에게 노출하지 않기 위해** 링크 삭제 대신 [활성/비활성] 토글 버튼을 클릭하여 잠시 숨김 처리한다.

### 2.4 링크 영구 삭제
- 소유자는 **더 이상 유효하지 않은 오래된 접속 정보나, 불필요해진 링크를 관리 목록에서 완전히 정리하기 위해** 해당 링크 카드에 있는 [삭제] 버튼을 클릭하여 목록에서 제거한다.

---

## 3. 향후 추가 예정 기능 (Nice-to-have) 연관 시나리오

- **소유자의 전체 페이지 공유:** 소유자는 **자신의 통합된 정보를 외부 플랫폼이나 지인에게 등록 및 알리기 위해** 화면 상단의 [내 링크 복사/공유] 버튼을 클릭하여 클립보드에 URL을 저장한다.
- **방문자의 단일 링크 복사:** 방문자는 **특정 카드의 정보(예: 흥미로운 영상이나 목적지)만을 타인에게 전달하기 위해** 카드 옆의 [복사] 아이콘을 누른다.
